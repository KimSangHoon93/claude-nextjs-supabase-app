# 소모임 이벤트 관리 MVP PRD

## 핵심 정보

**목적**: 소모임 주최자가 카카오톡 채팅 없이 이벤트 공지, 참여 신청, 명단 확인을 한 곳에서 처리할 수 있도록 한다
**사용자**: 수영, 헬스, 농구, 친구 모임 등 소규모 비정기·정기 모임을 직접 운영하는 주최자

---

## 사용자 여정

```
1. 랜딩 페이지
   ↓ "시작하기" 버튼 클릭

2. 로그인 페이지 / 회원가입 페이지
   ↓ 로그인 성공

3. 주최자 대시보드 (내 이벤트 목록)
   ↓ "이벤트 만들기" 버튼 클릭

4. 이벤트 생성 페이지
   ↓ 저장 완료

5. 이벤트 관리 상세 페이지
   ↓ 공유 링크 복사 → 참여자에게 전달

   [참여자 흐름]
   링크 수신 → 이벤트 공개 페이지 접속 (비로그인)
   ↓
   정원 여유 있음 → 참여 신청 폼 작성 → 참여 확정 (즉시)
   정원 초과 → "마감" 표시 (신청 버튼 비활성화)
   ↓
   공지 목록 페이지 (비로그인) → 공지 확인

   [주최자 흐름]
   이벤트 관리 상세 페이지
   ↓
   참여자 목록 페이지 → 참여자 확인 / 취소 처리
   공지 목록 페이지 → 공지 작성 페이지 → 공지 저장 + 이메일 발송

6. 완료
```

## 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명             | 설명                                                                                 | MVP 필수 이유                        | 관련 페이지                                          |
| -------- | ------------------ | ------------------------------------------------------------------------------------ | ------------------------------------ | ---------------------------------------------------- |
| **F001** | 이벤트 생성        | 제목, 설명, 장소, 시작/종료 시각, 정원을 입력하여 이벤트 생성, share_token 자동 발급 | 서비스의 핵심 시작점                 | 이벤트 생성 페이지                                   |
| **F002** | 이벤트 수정        | 이벤트 기본 정보 수정 (제목, 설명, 장소, 일시, 정원)                                 | 주최자가 일정/장소 변경 시 필수      | 이벤트 수정 페이지                                   |
| **F003** | 이벤트 삭제        | 이벤트 삭제 (상태를 cancelled로 변경)                                                | 잘못 만든 이벤트 정리                | 이벤트 관리 상세 페이지                              |
| **F004** | 이벤트 공개 페이지 | 비로그인 참여자가 share_token 링크로 이벤트 정보 조회, 정원 초과 시 마감 표시        | 참여자 가입 없는 접근의 핵심         | 이벤트 공개 페이지                                   |
| **F005** | 비로그인 참여 신청 | 참여자가 이름, 연락처(이메일 선택)만 입력하여 즉시 참여 확정, participant_token 발급 | 가입 없는 참여 신청이 핵심 가설      | 이벤트 공개 페이지                                   |
| **F006** | 참여자 목록 조회   | 주최자가 참여 확정/취소 참여자 명단 확인                                             | 명단 관리가 핵심 니즈                | 참여자 목록 페이지                                   |
| **F007** | 참여자 취소 처리   | 주최자가 특정 참여자 상태를 cancelled로 변경                                         | 노쇼 또는 취소 요청 처리             | 참여자 목록 페이지                                   |
| **F008** | 공지 작성          | 주최자가 이벤트별 공지 내용 작성 및 이메일 발송 여부 결정                            | 공지가 카톡에 묻히는 문제 해결       | 공지 작성 페이지                                     |
| **F009** | 공지 목록 조회     | 주최자 및 참여자(비로그인)가 이벤트 공지 목록 확인                                   | 참여자가 공지를 독립적으로 확인 가능 | 공지 목록 페이지 (주최자), 공지 목록 페이지 (참여자) |

### 2. MVP 필수 지원 기능

| ID       | 기능명           | 설명                                                                                | MVP 필수 이유              | 관련 페이지                                 |
| -------- | ---------------- | ----------------------------------------------------------------------------------- | -------------------------- | ------------------------------------------- |
| **F010** | 기본 인증        | 주최자 회원가입 / 로그인 / 로그아웃                                                 | 주최자 권한 구분 최소 인증 | 랜딩 페이지, 로그인 페이지, 회원가입 페이지 |
| **F011** | 이벤트 목록 조회 | 주최자가 자신이 만든 이벤트 목록 확인                                               | 대시보드 진입점            | 주최자 대시보드                             |
| **F012** | 이메일 알림 발송 | 공지 작성 시 이메일 입력 참여자에게 Resend + Supabase Edge Function으로 이메일 발송 | 참여자에게 공지 전달 수단  | 공지 작성 페이지                            |

- 프로필 상세 관리 (아바타, 자기소개 등)

## 메뉴 구조

```
공개 접근 (비로그인)
├── 랜딩 페이지
│   └── 기능: F010 (로그인/회원가입 진입)
├── 로그인 - F010
├── 회원가입 - F010
├── 이벤트 공개 페이지 (/e/[share_token])
│   └── 기능: F004 (이벤트 정보 조회), F005 (참여 신청)
└── 공지 목록 페이지 참여자용 (/e/[share_token]/announcements)
    └── 기능: F009 (공지 조회)

주최자 메뉴 (로그인 후 /protected)
├── 대시보드 (내 이벤트 목록)
│   └── 기능: F011 (이벤트 목록 조회)
├── 이벤트 생성
│   └── 기능: F001 (이벤트 생성)
└── 이벤트 관리 (선택한 이벤트)
    ├── 이벤트 관리 상세
    │   └── 기능: F002 수정 진입, F003 (이벤트 삭제)
    ├── 이벤트 수정
    │   └── 기능: F002 (이벤트 수정)
    ├── 참여자 목록
    │   └── 기능: F006 (목록 조회), F007 (참여자 취소)
    └── 공지 목록 / 공지 작성
        └── 기능: F008 (공지 작성), F009 (공지 조회), F012 (이메일 발송)
```

| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 서비스 소개 및 주최자 인증 진입점                                                                                                                                       |

## 데이터 모델

### events (이벤트)

| 필드        | 설명                  | 타입/관계                            |
| ----------- | --------------------- | ------------------------------------ |

| description | 이벤트 설명           | text                                 |
| location    | 장소                  | text                                 |
| starts_at   | 시작 일시             | timestamptz                          |
| ends_at     | 종료 일시             | timestamptz                          |
| capacity    | 정원                  | integer                              |
| share_token | 공유 링크용 고유 토큰 | text (unique)                        |
| status      | 이벤트 상태           | enum: active / cancelled / completed |

### participants (참여자)

| 필드              | 설명                  | 타입/관계                   |
| ----------------- | --------------------- | --------------------------- |

| event_id          | 소속 이벤트           | → events.id                 |
| name              | 참여자 이름           | text                        |
| contact           | 연락처 (이메일, 선택) | text                        |
| status            | 참여 상태             | enum: confirmed / cancelled |
| participant_token | 참여자 고유 토큰      | text (unique)               |
| note              | 메모 (선택)           | text                        |

| 필드       | 설명             | 타입/관계   |
| ---------- | ---------------- | ----------- |
| id         | 고유 식별자      | UUID        |
| event_id   | 소속 이벤트      | → events.id |
| content    | 공지 내용        | text        |
| email_sent | 이메일 발송 여부 | boolean     |
| created_at | 작성 일시        | timestamptz |
